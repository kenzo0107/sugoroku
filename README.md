# 世界のすごろく チェックシート

「世界のすごろく」で止まったマスをプレイヤーごとにチェックしていく Web アプリです。

- 一人ひとつコース（大自然満喫コース / 世界のショーとダンスコース / 冒険アクティビティコース / 世界のグルメコース / 古代文明ツアーコース）を選んで参加
- 行き先 6 か所とおみやげ 3 種をチェック、全部そろうとコンプリート
- 状態はブラウザの localStorage に保存（リロードしても消えません）

## 使い方

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
```

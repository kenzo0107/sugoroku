# 世界旅行すごろく

ブラウザで遊べる、世界を旅するすごろくです。

- 1〜4人で、1台の端末を順番に回して遊ぶ
- 一人ひとつコース（大自然満喫コース / 世界のショーとダンスコース / 冒険アクティビティコース / 世界のグルメコース / 古代文明ツアーコース）を選び、行き先6か所とおみやげ3種を集める
- 全部そろったらホノルルのマスをめざし、着いたらホノルルチャレンジ（1・3・5が出たら東京に帰ってゴール）
- ゲームの途中経過はブラウザの localStorage に保存（リロードしても続きから遊べる）

実物の盤面で遊ぶとき用のチェックシートは `checklist.html` にあります。

## 使い方

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
```

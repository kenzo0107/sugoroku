# すごろく チェックシート

「世界のすごろく」「日本一周すごろく」で止まったマスをプレイヤーごとにチェックしていく Web アプリです。

## 世界のすごろく（index.html）

- 一人ひとつコース（大自然満喫コース / 世界のショーとダンスコース / 冒険アクティビティコース / 世界のグルメコース / 古代文明ツアーコース）を選んで参加
- 行き先 6 か所とおみやげ 3 種をチェック、全部そろうとコンプリート

## 日本一周すごろく（japan.html）

- 一人ひとつコース（お祭りめぐりコース / お城めぐりコース / おいしいものコース / 温泉めぐりコース / 映えスポットコース）を選んで参加
- 行き先 6 か所をチェック、全部そろうとコンプリート
- 小学一年生でも読めるよう、漢字にはふりがなを付けている

状態は盤面ごとにブラウザの localStorage に保存します（リロードしても消えません）。

## 使い方

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
```
